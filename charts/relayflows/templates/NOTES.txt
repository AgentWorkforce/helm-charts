Relayflows standalone Job {{ include "relayflows.jobName" . }} was installed.

This run is local to Kubernetes. It does not register with or depend on Agent
Relay Cloud. The `flows` CLI starts relayflowd inside the pod and stores durable
run journals on PVC {{ include "relayflows.pvcName" . }}.

Watch the run:
  kubectl logs --namespace {{ .Release.Namespace }} job/{{ include "relayflows.jobName" . }} -c runner --follow
  kubectl get job --namespace {{ .Release.Namespace }} {{ include "relayflows.jobName" . }}

To resume a suspended or interrupted run, upgrade the release with:
  helm upgrade {{ .Release.Name }} <same-chart-reference-used-for-install> --namespace {{ .Release.Namespace }} --reuse-values --set standalone.resumeRunId=<run-id>

The CLI prints the run ID as `RUN <run-id> ...`. It is also the journal filename
under {{ .Values.standalone.dataDir }}/runs/<run-id>.sqlite3 on the PVC. Record
it before enabling completed-Job TTL cleanup, which also removes pod logs.
